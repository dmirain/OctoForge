# Code of Conduct

OctoForge is a small, solo-maintained project. The rules here are short on purpose.

## The short version

Be respectful. Disagree about code, architecture, or ideas as much as you like — that's normal and healthy. Don't make it personal, don't harass anyone, and don't post anything discriminatory, abusive, or off-topic in issues, pull requests, or discussions.

## If someone breaks that

Report it by opening an issue, or, if you'd rather keep it private, use this repo's private vulnerability reporting form (Security tab → **Report a vulnerability**) — it's meant for security issues, but it's also the only private, non-email channel GitHub gives this repo, so use it for conduct concerns too if that's what you need.

The maintainer will look into it and, depending on severity, that can mean anything from a warning to deleting comments to blocking someone from the repository. There's no formal appeals process — this is a one-person project, not a foundation.

## Scope

This applies to this repository: issues, pull requests, discussions, and commits.
