# OctoForge

Мультипользовательский LLM-агент: скилы на Jinja-DSL, знания в БД, фоновые задачи.
Дизайн — в [docs/design.md](docs/design.md), конвенции кода — в [AGENTS.md](AGENTS.md).

## Структура репозитория

Монорепо из двух независимых Python-проектов:

- `core/` — библиотека `octoforge-core`: домен, порты, сервисы, клиенты LLM. Свои зависимости и тесты.
- `web/` — приложение `octoforge-web`: FastAPI-обёртка над библиотекой, чат-UI. Свои зависимости и тесты.

## Быстрый старт

```bash
make install          # создать .venv и поставить оба проекта (editable, с dev-зависимостями)
cp .env.example .env  # заполнить OF_LLM_API_KEY и при необходимости OF_LLM_BASE_URL / OF_LLM_MODEL
make run              # uvicorn с автоперезагрузкой
```

Открыть http://127.0.0.1:8000 — чат с LLM. Поле «Как вас зовут?» задаёт имя,
которое попадает в приветствие и в системный промпт.

## Проверки

```bash
make check  # ruff (lint + format) → mypy → pytest для обоих проектов
```

Отдельно: `make lint`, `make typecheck`, `make test`, `make format`.
