# Archive

These files are **not the documentation**. They are the working notes this project was built
from: design discussions, comparative research, audit findings, migration plans. They are in
Russian, they mix decisions with the reasoning that led there, and parts of them describe states
the code has already left behind.

Nothing here is maintained. Nothing in `docs/` links here.

The current documentation lives one directory up — start at [../README.md](../README.md). When the
two disagree, the code is right, then the current docs; these notes are last.

They are kept for one reason: some of them contain research that would be expensive to redo
(code-level studies of other agent projects, latency measurements, considered-and-rejected
options). If you need the *why* behind something the current docs only state, it is probably here —
and probably out of date on the details.
